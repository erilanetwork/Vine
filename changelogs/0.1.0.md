# Vine 0.1.0

The first release of Vine, a Minecraft Java Edition proxy written in Rust on top of the Pumpkin crates.

## Highlights

- Clients from 1.7 to 26.x on one proxy, with server switching on every version. On 1.20.2 and newer, switches go through the configuration phase, so the client is fully reconfigured for the new server.
- Vine forwarding for Pumpkin backends. Player data is signed with Ed25519 and carries a timestamp and a nonce, so a backend can trust it and a captured login cannot be replayed. `vine --init` prints the public key each backend needs.
- WebAssembly plugins built against the interface in `wit/`. Plugins can listen to events, register commands with tab completion, rewrite unsigned chat and commands, send plugin messages, move and kick players and ship their own translations. `/vine reload` reloads them without a restart.
- An interactive console with tab completion, inline hints and command highlighting.

## Proxy

- Forced hosts route players by the domain they joined with, with an optional MOTD and status icon per backend.
- A fallback server catches players whose target server is down, both on join and when a backend goes away.
- Commands: `/server`, `/send`, `/list`, `/glist`, `/status`, `/help` and `/vine`. Commands the proxy does not handle are passed on to the backend.
- Permissions with groups, inheritance, wildcards and negated nodes, configured in `vine.toml`.
- Per player translations loaded from `lang/`, picked from the client's language. Messages support hex colors.
- The client's settings and brand are repeated to every backend it switches to.

## Performance

- Compression uses zlib-rs and reuses its state across packets.
- Compressed backend packets are passed through untouched when nothing needs to read them.
- Each player's client and backends are read and written by long-lived tasks, so a server switch loses no packets and queued writes go out in one flush.

## Security

- Online mode authentication against Mojang, with optional `prevent_proxy_connections`.
- Per IP connection rate limits, with IPv6 clients grouped by /64.
- Packet flood limits and size caps, both before and after login, including the inflated size of compressed packets.
- Strict username validation and duplicate login protection.
- PROXY protocol v1 and v2, accepted only from configured trusted proxies.
- Plugins run sandboxed with caps on memory, tables, open files, call time, event handlers, commands and translations. A plugin that hangs or crashes is disabled instead of stalling the proxy.
- `vine-forwarding.key` is generated with owner only permissions.

## Deployment

- Prebuilt binaries for Linux (glibc and static musl), Windows and macOS, on x86_64 and ARM64 where available, with SHA256 checksums.
- Docker images for x86_64 and ARM64 at `ghcr.io/erilanetwork/vine` and `erilanetwork/vine` on Docker Hub, and a compose file in `docker/`. The image runs as an unprivileged user and health checks the configured port.
- A Pterodactyl egg that verifies its download against the release checksums.
- `VINE_BIND_ADDRESS` overrides the listen address for panels that pick the port at start.
